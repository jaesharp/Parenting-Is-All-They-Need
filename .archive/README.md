# Archive Index

This directory preserves important artifacts from the project's evolution. Rather than just storing old files, it documents key moments and transitions in our thinking.

## Purpose
- **Historical Record**: Preserves the journey, not just the destination
- **Learning Repository**: Documents what we tried and why we changed
- **Reference Points**: Marks significant shifts in approach
- **Transparency**: Shows how ideas evolved

## Directory Structure
```
.archive/
├── README.md         # This index
└── article/          # Pre-collaboration article attempts
    └── ACM_AI_Alignment_Article.*  # Various early versions
```

## How to Use This Archive

1. **For Understanding Evolution**: Compare archived versions with current to see changes
2. **For Learning**: Understand why certain approaches were abandoned
3. **For Documentation**: Reference in papers about methodology development
4. **For Transparency**: Show complete development history

## Adding to the Archive

When archiving materials:
1. Create descriptive subdirectory
2. Add README explaining what and why
3. Update this index with:
   - What was archived
   - When it represents
   - Why it's significant
   - What we learned
