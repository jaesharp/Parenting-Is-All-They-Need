# Meta Documentation

This hidden directory contains internal project documentation, planning materials, and the development history of our collaboration framework.

## Structure

```
.meta/
├── docs/                    # Internal documentation
│   ├── thynk-collaboration/ # Complete framework development
│   ├── *_notes.md          # Various planning documents
│   └── *_review.md         # Internal reviews and checks
└── README.md               # This file
```

## Purpose

This directory preserves:
- Our thinking process
- Framework development history
- Internal deliberations
- Meta-documentation about the project

## Important Note on Transparency

**This directory is part of the project repository** - it's prefixed with a dot to indicate it contains meta/internal documentation rather than the main article content. These documents:
- Show our development process transparently
- Document how we arrived at our decisions
- Preserve the evolution of our thinking
- Are fully tracked in version control

## Distinction

- `.meta/docs/` - HOW we developed our approach (process documentation)
- `docs/thynk-collaboration/` - WHAT we're actively using (working documents)

Both are open and shareable. The distinction is organizational, not about privacy or secrecy.
