# Collaboration Guidelines

## Working in docs/research/

This directory is our shared workspace. All collaborators work here as equals.

### File Organization
- `literature/` - Academic papers and references
- `drafts/` - Work-in-progress sections
- `discussions/` - Conversation threads on specific topics
- `data/` - Any empirical data or examples
- `notes/` - Individual working notes (use your identifier)

### Collaboration Practices

#### Contributing Ideas
- Add thoughts to relevant `.md` files
- Create new files for substantial new directions
- Use clear headings and date your contributions
- Build on others' ideas with attribution

#### Making Changes
- Edit directly - this is collaborative space
- Use comments `<!-- Like this -->` for meta-discussion
- Mark uncertain points with `[?]`
- Flag needs with `[TODO: specific need]`

#### Tracking Progress
- Update `progress-log.md` with significant developments
- Note breakthroughs in `insights.md`
- Document dead ends in `attempted-approaches.md`

### Working Asynchronously
- Leave clear context for others
- Summarize long discussions
- Flag urgent needs clearly
- Respect different working styles

## Specific Research Tasks

### For Citation Research
1. Find potential sources
2. Add to `literature/candidates.md` with summary
3. Evaluate relevance (1-10 scale)
4. Note which claim it supports
5. Add concerns or caveats

### For Concept Development
1. Start with question or insight
2. Explore implications
3. Connect to existing framework
4. Identify what's needed to support it
5. Note open questions

### For Technical Integration
1. Identify mathematical concept
2. Find parenting/developmental parallel
3. Work out formal connection
4. Create accessible explanation
5. Test with examples

## Communication Norms

### Clarity Over Cleverness
- Define technical terms
- Explain reasoning steps
- Provide context for newcomers
- Use examples liberally

### Building Together
- "Yes, and..." preferred over "No, but..."
- Question assumptions respectfully
- Celebrate partial progress
- Learn from different perspectives

### Managing Disagreement
- Focus on understanding first
- Articulate cruxes clearly
- Seek synthesis where possible
- Document multiple viable paths

## Quality Standards

### For Research
- Primary sources preferred
- Recent work valued
- Cross-disciplinary connections encouraged
- Empirical grounding sought

### For Writing
- Clear thesis statements
- Logical flow
- Technical accuracy
- Accessible explanations

### For Collaboration
- Inclusive communication
- Timely responses
- Constructive feedback
- Shared ownership

---

*These guidelines support productive collaboration while respecting diverse working styles and perspectives.*
