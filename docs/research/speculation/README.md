# Speculation Research

This directory contains speculative research exploring potential future directions and untested hypotheses. Each subdirectory represents a different area of speculation.

## Subdirectories

### [parenting-ml-predictions/](./parenting-ml-predictions/)
Predictions about machine learning techniques that could be discovered by applying parenting principles. Includes experimental designs, detection methods, and counterfactual validation approaches.

## Purpose

The speculation section serves to:
1. Document forward-looking hypotheses before they're tested
2. Provide detailed experimental frameworks for validation
3. Separate untested ideas from validated research
4. Enable pre-registration of predictions
5. Foster creative exploration while maintaining rigor

## Guidelines

When adding new speculations:
- Create a dedicated subdirectory
- Include README with summary and index
- Separate each major speculation into its own file
- Provide testable hypotheses
- Include experimental designs
- Document counterfactual tests
- Consider ethical implications

## Status

All content in this directory should be considered:
- Untested hypotheses
- Forward-looking predictions
- Experimental proposals
- Not yet peer-reviewed
- Subject to revision based on evidence
